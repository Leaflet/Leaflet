# Carta Nova

**Carta Nova** is a free and open-source (MIT License) Android application designed to easily display LeafletJS maps on mobile devices in offline mode. 

### How it works:
1. Build your static map project on your computer.
2. Zip your assets folder.
3. Import the zip file into **Carta Nova** to view your map offline.
