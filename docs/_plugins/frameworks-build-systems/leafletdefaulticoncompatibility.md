Reads the default icon options from CSS, so that marker icon URLs work with bundlers and frameworks that rewrite URLs in CSS (webpack, Rails Asset Pipeline, Django pipeline). Fixes [#4968](https://github.com/Leaflet/Leaflet/issues/4968).
