Renders GeoJSON regions with per-feature colors, permanent labels and click/hover popups, bound to data through a simple key → object map. The base of [leaflet.us-states](https://github.com/EricDalnas/leaflet.us-states) and [leaflet.countries](https://github.com/EricDalnas/leaflet.countries).
